# Pomodoro — React + TypeScript</br>
Aplicativo Pomodoro simples e elegante feito em React com TypeScript para ajudar você a focar no trabalho e gerenciar descansos de forma eficiente.</br>
Link para acessar o aplicativo: https://mypersonalpomodor.netlify.app/

## Visão geral</br>
O aplicativo possui dois modos principais:
  ####  Trabalhando:
   - Cronômetro configurado em 25 minutos por pomodoro.
   - Início do pomodoro sinalizado por dois bipes.</br>
   
  ####  Descansando:
   - Para cada pomodoro completado você ganha um descanso de 5 minutos.
   - A cada 4 ciclos de trabalho (4 pomodoros) o descanso é estendido para 15 minutos. </br>
      
O app também exibe informações úteis em tempo real:</br>
  - Quantos ciclos já foram concluídos.</br>
  - Quantas horas trabalhadas (acumulado).</br>
  - Quantos pomodoros concluídos.</br>


## Funcionalidades</br>
 - Alternância entre os modos Trabalhando e Descansando.</br>
 - Iniciar / pausar / resetar o cronômetro.</br>
 - Sinal sonoro de início (dois bipes) ao começar um pomodoro.</br>
 - Lógica de descanso curto (5 min) e descanso longo (15 min a cada 4 pomodoros).</br>
 - Contador de ciclos concluídos, pomodoros e horas trabalhadas.</br>
 - Interface responsiva e acessível.</br>
 - Contador de ciclos concluídos, pomodoros e horas trabalhadas.</br>
